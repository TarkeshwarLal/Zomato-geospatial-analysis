**Zomato Geospatial Analysis**

📌 Project Overview

This project analyzes the relationship between online orders and ratings for restaurants on Zomato. The analysis delves into text-based insights through Unigram, Bi-gram, and Trigram analysis and concludes with a geospatial analysis to visualize the distribution and trends of restaurant ratings across different locations.

📊 Key Objectives

Understand how online orders correlate with customer ratings.

Perform natural language processing (NLP) techniques (Unigram, Bi-gram, and Trigram analysis) on customer reviews.

Conduct geospatial analysis to visualize rating patterns across various regions.

📂 Dataset

The dataset used in this project is sourced from Zomato.

Contains information on restaurant names, locations, ratings, reviews, online order availability, and more.

🛠️ Technologies & Tools Used

Python (Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn)

Natural Language Processing (NLP) (NLTK, TextBlob)

Geospatial Analysis (Folium, Geopandas)

Data Visualization (Seaborn, Plotly, Matplotlib)

Jupyter Notebook

🔍 Analysis & Methodology

Data Preprocessing:

Handling missing values and outliers.

Converting categorical data into numerical formats.

Correlation Analysis:

Analyzing the impact of online orders on ratings.

Visualizing the relationship using scatter plots and heatmaps.

Unigram, Bi-gram, and Trigram Analysis:

Tokenizing text data from reviews.

Identifying common words and phrases using N-gram analysis.

Geospatial Analysis:

Mapping restaurants based on locations.

Identifying rating trends across different areas.

Visualizing insights using Folium maps.

📈 Results & Insights

Online order availability has a significant impact on customer ratings.

Common words and phrases extracted from N-gram analysis provide insights into customer sentiment.

Geospatial visualization reveals clusters of high-rated restaurants in certain locations.

📌 Future Improvements

Implementing Machine Learning models to predict restaurant ratings.

Enhancing sentiment analysis with deep learning techniques.

Expanding the analysis with more geospatial insights.
